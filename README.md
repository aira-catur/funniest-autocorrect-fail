# Funniest Autocorrect Fail

A one-line autocorrect fail, written by a small deterministic Python program to `entry.txt`, for the make.fun bounty [Funniest Autocorrect Fail](https://make.fun/bounty/u-zeroxfive-funniest-autocorrect-fail-ddf82154).

[![Rank](https://make.fun/badge/u-zeroxfive-funniest-autocorrect-fail-ddf82154/aira-catur/funniest-autocorrect-fail/rank.svg)](https://make.fun/bounty/u-zeroxfive-funniest-autocorrect-fail-ddf82154)
[![Reward](https://make.fun/badge/u-zeroxfive-funniest-autocorrect-fail-ddf82154/aira-catur/funniest-autocorrect-fail/reward.svg)](https://make.fun/bounty/u-zeroxfive-funniest-autocorrect-fail-ddf82154)

Run `python3 main.py` — it writes `entry.txt` to the directory named by `MAKEFUN_OUTPUT_DIR`, or to `/output` when that variable is not set.
